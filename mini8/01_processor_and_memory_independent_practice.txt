GETTING STARTED
----------------------------------------------------------------------
Save a copy of the lesson notebook as 01_practice_yourname.ipynb in the
same folder as the original notebook. Run its setup cell in Section 0.
Add your own Markdown and code cells at the end, labelled by task number.
Keep both your original predictions and your corrected explanations.

Create a fresh CPU for each new experiment. This Python template is ready
to use after the setup cell. Replace the comment with your assembly
instructions, keeping HALT as the final instruction:

source = """
; Write your MINI-8 instructions here.
HALT
"""
practice_cpu = CPU(source, watch=(20, 21), title="Independent practice")
practice_cpu.show()

In a separate code cell, use practice_cpu.step() to execute one instruction
or practice_cpu.run() to continue to HALT. The watch setting displays data
cells 20 and 21; it does not put any values into those cells.

After editing source, rerun the cell that creates CPU(source, ...).
practice_cpu.reset() restores the initial state of the program already
loaded into that CPU; it does not execute it or assemble your edited source.
Use run() after reset() to execute it again. Calling run() again after HALT
without a reset does not restart execution.

Use only the instructions introduced in Lecture 1:
LDI, MOV, ADD, SUB, STORE, LOAD, OUT, HALT, and the .equ directive.
All numbers in the tasks are decimal unless explicitly marked as binary
or hexadecimal. M[20] means the value in data-memory cell 20.
