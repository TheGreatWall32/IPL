TASK 6 - READ TOKENS, GRAMMAR, AND EXPRESSION TREES
----------------------------------------------------------------------
Notebook reference: Section 9.1; lecture slides 20-23.

Use the conceptual grammar from the lecture:

    assignment ::= NAME "=" expression
    expression ::= atom { ("+" | "-") atom }
    atom       ::= NAME | NUMBER | "(" expression ")"

Braces mean zero or more repetitions. Ungrouped additions and subtractions
associate from left to right. This grammar describes a teaching example;
there is no supplied parser to run for these questions.

a) Write the tokens of z = a - (b + c) in order. Classify each as a name,
   assignment sign, arithmetic operator, or parenthesis. For z = a + 12,
   also identify the number token. Is 12 one number token or two?

b) Draw the assignment AST for z = a - (b + c). Include the assignment
   target and Name, Add, and Sub nodes. Identify which subtree supplies
   the value subtracted from a. Connect the arithmetic nodes with the
   relevant instructions in your Task 5 program.

c) Draw a second AST for z = a - b + c. Evaluate both expressions for
   a = 20, b = 7, c = 4. Explain the different grouping and results.

d) For each statement below, decide whether its token structure fits the
   grammar. Then consider the separate value and initialization rules.
   Assume a, b, and c are initialized, but missing is not; z may be new.

       z = a +
       z = (a + b
       z = a + missing
       z = a + 300

   Explain the difference between an invalid structure, a read of an
   uninitialized variable, and a literal outside the permitted byte range.
   Do not treat the grammar alone as a complete definition of the language.
